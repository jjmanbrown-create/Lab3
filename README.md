# Lab 3 – Java Programming Projects

This repository contains four Java programming tasks completed as part of CISC 230 (Object-Oriented Design and Programming) at the University of St. Thomas. Each task focuses on applying Java programming concepts through interactive applications and graphical interface development.

## Task 1: Board Game Turn Generator
Developed a board game turn generator that allows a user to enter their name and select a character to generate a player turn.

**Features:**
- Accept player names and character selections using an enum type.
- Display player information through a player tag.
- Use Java's `Random` class to generate two dice values.
- Use Java's `Math` class to determine the higher and lower dice values.
- Calculate a movement score based on the dice results.

## Task 2: Mini Solar System
Created a graphical representation of a mini solar system using JavaFX and various shape objects.

**Features:**
- Use JavaFX shape objects to represent solar system elements.
- Customize shape colors using color-setting methods.
- Organize created objects into a `Group`.
- Display the completed solar system within a JavaFX scene.

## Task 3: College Dorm Room Designer
Designed a graphical scene representing a college dorm room using JavaFX rectangle objects and randomly generated colors.

**Features:**
- Create dorm room elements using rectangle shapes.
- Represent objects such as a desk, desk legs, window, and decorations.
- Use JavaFX shape objects to build the room layout.
- Generate a random wall color each time the program runs using Java's `Random` class.

## Task 4: Tommie Student ID Card
Created a graphical student ID card for a University of St. Thomas student using JavaFX shape objects.

**Features:**
- Design an ID card using circle and rectangle objects.
- Customize the appearance of shapes using color-setting methods.
- Organize graphical elements within a JavaFX scene.
- Create a visual representation of a university student ID card.
